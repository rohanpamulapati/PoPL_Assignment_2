
# P1 Report — Logic Puzzle Solver

## Group 57

## 1. Approach

The program uses SWI-Prolog to solve the logic puzzle involving four friends: Alex, Ben, Carla, and Dana.

Each friend has exactly one department, programming language, and project.

The predicate `candidate_solution/1` generates all possible assignments using permutations.

Each clue is implemented independently using `clue/2`.

The predicate `count_solutions/2` counts the assignments satisfying a specified list of clues.

## 3. Additional Clue 9

**Clue 9:** The friend working on the AI project uses Python.

Prolog implementation:

```prolog
clue(9, Solution) :-
    member(p(_, _, python, 'AI'), Solution).
```

This clue does not mention any friend's name.

It reduces the number of solutions satisfying the original eight clues from 3 to 1.
