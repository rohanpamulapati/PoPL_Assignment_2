## Prompt 1 (split_list)
Following the prolog-dev skill file (57/skills/prolog-dev/SKILL.md in our repo), write only a predicate split_list(List, Left, Right) for P2 of the assignment. It splits List into two non-empty lists Left and Right, in order, so that appending Left and Right gives List, and it enumerates every such split on backtracking. It must fail for lists of length 0 and 1. Use only the allowed libraries. Explain its declarative reading and its base case briefly.

## Prompt 2 (expr)
Following the prolog-dev skill file, write only a predicate expr(List, Tree, Value) for P2 of the assignment. List is a non-empty list of non-negative integers. Tree is an expression tree over all the numbers of List in order: n(Number) for a single number, or e(Op, LeftTree, RightTree) where Op is one of +, -, *, / and the two sides come from splitting the list with the existing split_list. Value is the integer value of Tree. Division is only allowed when the divisor is not zero and the division is exact, and this applies to every division inside the tree. Values of sub-expressions may be negative, and there is no unary minus. It enumerates every tree on backtracking and fails for the empty list. Use only the allowed libraries. Explain its declarative reading and its base case and recursive case briefly.

## Prompt 3 (expr_string)
Following the prolog-dev skill file, write only a predicate expr_string(Tree, String) for P2 of the assignment, for the expression trees n(Number) and e(Op, LeftTree, RightTree) from expr/3. String is the canonical SWI-Prolog string of the tree, with no spaces and numbers in decimal. The rule: * and / bind tighter than + and -, operators are left-associative, a left operand is written in parentheses only if its top operator has lower precedence than its parent's, a right operand is written in parentheses if its top operator has the same or lower precedence than its parent's, and a single number is never in parentheses. Examples: the tree for (4+2)*3 gives "(4+2)*3", the tree for 8/4*2 gives "8/4*2", 8/(4*2) gives "8/(4*2)", 1-2-3 gives "1-2-3", 1-(2-3) gives "1-(2-3)", and 1+(2+3) gives "1+(2+3)". Do not build a string and parse it back. Use only the allowed libraries. Explain briefly how the parentheses rule is applied.

## Prompt 4 (equation_string)
Following the prolog-dev skill file, write only a predicate equation_string(List, Equation) for P2 of the assignment, using the existing split_list, expr and expr_string. Equation is the canonical string of one valid equation for List: split List into a non-empty left part and a non-empty right part with split_list, build an expression tree for each part with expr so that both trees have the same integer value, and join the two canonical strings with = and no spaces, for example "4*2=5+3". It enumerates every valid equation on backtracking, one for each pair of trees, and fails for lists of length 0 and 1 or when there is no valid equation. Do not build a string and parse it back. Use only the allowed libraries. Explain briefly how it works.

## Prompt 5 (generate_equation and the list predicates)

Do not build a string and parse it back. Do not print anything. Use only the allowed libraries. Explain briefly how each one works.
